# Microsoft 365 Copilot — Hands-on Walkthrough

A single-page, self-contained hands-on walkthrough for Microsoft 365 Copilot.

**Live page:** https://gd120msft.github.io/southwest-copilot-hands-on/

## What it covers

1. **The prompting pattern** — Goal · Context · Source · Expectations
2. **Personalization & memory** — set Copilot up once so it persists
3. **Grounding** — point it at the right meeting, mail or file, and ask it to cite
4. **Working across your applications** — Chat → Word → PowerPoint as one chain
5. **Inside the file** — Ask Copilot in Excel vs. Edit with Copilot
6. **Make it stick** — a seven-day plan

Every prompt has a copy button. Use ← and → to move between steps.

## Sample data

The page embeds a sample workbook, `LoneStar-Air-Q3-Network-Data.xlsx`, for the Excel
section. **Lone Star Air is a fictional carrier** — every figure in the workbook is
synthetic and none of it reflects any real airline. It is safe to project, share and upload.
